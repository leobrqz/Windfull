# Diagnóstico do WindFull

O host Windows grava logs locais diários nesta pasta:

```text
%LOCALAPPDATA%\io.github.leobrqz\WindFull\logs
```

O aplicativo retém até 14 arquivos diários. Em **Ajustes → Rede → Diagnóstico**, use **Abrir pasta** para acessá-los.

Os registros incluem inicialização do host, erros da ponte Samsung, erros JavaScript/React, falhas de comandos da interface, mudanças de foco e a seção de ajustes selecionada. Valores enviados a comandos de controle e códigos de pareamento não são registrados. Mensagens de erro podem conter endereços da rede local; revise os arquivos antes de compartilhá-los.
